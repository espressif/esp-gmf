About
=====

:link_to_translation:`zh_CN:[中文]`

This guide is the official documentation for `ESP-GMF <https://github.com/espressif/esp-gmf>`_. ESP-GMF (Espressif General Multimedia Framework) is developed by `Espressif Systems <https://espressif.com>`_ and is a general-purpose multimedia framework for IoT device audio, video, image, and streaming data processing, built on `ESP-IDF <https://github.com/espressif/esp-idf>`_ and covering all Espressif chips.
