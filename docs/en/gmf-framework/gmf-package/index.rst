GMF Packages
============

:link_to_translation:`zh_CN:[中文]`

Packages are encapsulation modules in ESP-GMF targeting specific application scenarios, typically combining multiple basic or atomic components. They encapsulate common multimedia workflows, hide the underlying pipeline construction and component configuration logic, and expose application-oriented interfaces, reducing repetitive boilerplate code. This category also includes utility modules and example collections.
