GMF 高级组件
======================

:link_to_translation:`en:[English]`

高级组件是 ESP-GMF 中面向特定应用场景的封装模块，通常由多个基础功能组件或原子组件组合而成。它们封装常见的多媒体业务流程，隐藏底层的处理链（pipeline）构建和组件配置逻辑，对外提供面向应用场景的接口，减少用户重复编写流程代码。该分类还包括一些工具类模块和示例集合。
