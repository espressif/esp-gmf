# Documentation Source Folder

This folder contains source files of **ESP-GMF documentation** available in [English](https://docs.espressif.com/projects/esp-gmf/en/latest/) and [Chinese](https://docs.espressif.com/projects/esp-gmf/zh_CN/latest/).

The sources do not render well in GitHub and some information is not visible without building the documentation.

Use the actual documentation, which is generated within about 20 minutes of each commit:

# Hosted Documentation

* English: <https://docs.espressif.com/projects/esp-gmf/en/latest/>
* Chinese: <https://docs.espressif.com/projects/esp-gmf/zh_CN/latest/>

The above URLs point to the latest version on the `main` branch. For offline reading, click the **Download HTML** link in the bottom-right version selector to grab the whole site as a single `.zip` archive. The docs currently focus on online HTML browsing; a PDF version is not provided at the moment.

# Building Documentation

The documentation is built using the Python package `esp-docs`. Install the pinned build dependencies (which include `esp-docs` itself plus the `sphinxcontrib-mermaid` Sphinx extension used by some diagrams):

```bash
pip install -r requirements.txt
```

For a summary of available options, run:

```bash
build-docs --help
```

To build the English HTML locally (default builder is `html`):

```bash
build-docs -l en build
```

The build output lands in `_build/<lang>/generic/html/`. That directory also
contains `esp-gmf-<lang>-<version>.zip`, generated by the
`esp_docs.esp_extensions.add_html_zip` extension, which is what the docs site serves as **Download HTML**.

For more information, see the `esp-docs` documentation at <https://github.com/espressif/esp-docs/blob/master/README.md>.
